# UW Fashion for Change Website

*Lights, camera, action!*

**Fashion for Change (FC)** is a large, social, and creative community running the largest annual student-led charity fashion show in the Kitchener-Waterloo region. Associated with the **University of Waterloo**, Wilfred Laurier University, and Conestoga College, FC is a philanthropic approach to sustainable fashion.

This website is a lasting gallery of art’s fleeting beauty, keeping our students’ creations alive long after the curtain falls.
